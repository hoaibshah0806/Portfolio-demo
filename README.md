# Portfolio-demo
A high-performance, single-page developer portfolio blending backend engineering (Java, Go, Kafka) with a modern "Solo Leveling" 3D aesthetic.
Portfolio — Mohammed Shoaib Shah

This repository contains the source code for a high-velocity developer Portfolio designed with a "Solo Leveling" (anime) aesthetic. It visually bridges my background as a district-level 100m/200m sprinter with my technical expertise in backend systems, AI/ML, and Cloud architecture.

Core Concept: "Engineering at the Speed of Thought"
The UI/UX is built to feel like a high-tech "System Interface," utilizing deep obsidian backgrounds, neon electric blue accents, and smooth scroll-driven animations to create a fast, immersive experience without bloated libraries.

Key Features:

3D Hero Section: Integrated lightweight 3D elements (via Spline) that react to user interaction, representing the "Awakening" of a player.

System UI Stats: A translucent, glowing status window detailing academic progression at Trinity Academy of Engineering and athletic achievements.

Bento Box Inventory: An interactive CSS grid showcasing the tech stack (Spring Boot, GoLang, Kafka, DevOps) with snappy glassmorphism hover effects.

Quest Log Timeline: A stylized project showcase built with GSAP scroll animations that slide in as the user navigates.

Tech Stack:

Frontend Framework: React (via Vite)

Styling: Tailwind CSS (Dark Mode)

Animations: GSAP (ScrollTrigger)

3D Assets: Spline / @splinetool/react-spline

Icons: Lucide React
